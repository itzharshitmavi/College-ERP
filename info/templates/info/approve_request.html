Academic Session & Semester Management

The active session is the college calendar. Each student's batch session is calculated from admission year and semester: semesters 1–2 use the admission-year session, semesters 3–4 use the next session, and so on. Promote Semester advances only students whose next semester belongs to the active session. Set Semester is an explicit admin correction for the filtered cohort and never moves students backwards.
